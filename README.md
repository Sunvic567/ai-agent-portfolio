# Sunday Victor | AI Agent Engineer

A light, responsive portfolio featuring seven AI, agent, and application projects from https://github.com/Sunvic567. Plain HTML, CSS, and JavaScript; no build, backend, API keys, or paid services required.

## Publish on GitHub Pages

1. Create a new public repository named `ai-agent-portfolio` in your GitHub account.
2. Upload `index.html`, `style.css`, `script.js`, `.nojekyll`, and this README to the repository root. Do not upload the containing folder as another directory.
3. Open **Settings > Pages**. Under **Build and deployment**, select **Deploy from a branch**.
4. Select **main** and **/(root)**, then Save.
5. GitHub will display the deployed URL after publishing. For this repository name, the expected address is `https://sunvic567.github.io/ai-agent-portfolio/`.

If you want `https://sunvic567.github.io/` as your main portfolio address, use the repository name `Sunvic567.github.io` instead, provided it is not already used. A custom domain can be added in Pages settings later.

## Local preview

Open index.html, or run `python3 -m http.server 8000` in this directory and visit http://localhost:8000.

## Edit

- Name, bio, title, contact links: `index.html`.
- Projects, descriptions, tags, and case-study details: `script.js`.
- Colors, layout, and typography: `style.css`.
- Update the email in both HTML and JavaScript if it changes.

Project descriptions are based on repository READMEs. They are not independent verification of deployed services or performance. Reflect AI is included as a planning prototype. Its current planner uses editable templates rather than a remote language model. No private prototype URLs or secrets are included.
